Console Command Reference

Developer documentation for the CakePHP shell commands in the Taiwan Election Directory (選舉黃頁). These shells handle data import, tree management, and export for election, candidate, and area records.

# All commands run via the CakePHP console:
$ ./cake2/lib/Cake/Console/cake <shell> [method] -app /home/kiang/public_html/elections

# If no method is specified, the shell's main() is called.
# Available shells: ae, area, bulletin, candidate, cec, election,
# export, import, json, keyword, polygon, report, vote2026

Key Models & Relationships

Election

Tree behavior (parent_id / lft / rght). HABTM Area via areas_elections, HABTM Bulletin via bulletins_elections. hasMany Candidate (fk: election_id), hasMany AreasElection. Typical hierarchy: root year → election type → city → district → cunli.

Area

Tree behavior. HABTM Election via areas_elections. hasMany AreasElection. Fields include ivid, code (govt codes), polygons (GeoJSON). beforeSave propagates name changes to linked elections.

Candidate

belongsTo Election. HABTM Tag, Keyword. beforeSave auto-resizes uploaded images to 512×512 via Imagick and normalises dot separators in names. Cached views: CandidatesView{id}.

AreasElection

Join model for areas_elections. belongsTo Area (fk: Area_id), belongsTo Election (fk: Election_id). Used for explicit many-to-many lookups that HABTM alone can't filter on.

Vote2026Shell Vote2026Shell.php

Imports 2026 village/borough chief (村里長) candidate registrations from CEC data. Parses area strings like 臺北市松山區莊敬里 into city/district/cunli, builds missing election tree nodes, links cunli elections to area records, and creates candidate records.

Election Area self-contained
MethodPurpose
importCunliCandidatesMain entry point. Reads data/vote2026_cunli_candidates.csv, builds election + area tree indexes in memory, creates missing election nodes (district and cunli level) with default population/quota values, creates missing area records, links via areas_elections, inserts or updates candidates (name, party, stage=1, is_reviewed=1). Sanitises 4-byte UTF-8 (CJK Extension B/C) to ?. Runs Election→recover() at the end if new tree nodes were added.
Dependencies
  • data/vote2026_cunli_candidates.csv — CEC 村里長 registration CSV (included in repo)
Hardcoded IDs
  • 8e52f4d0-f3cc-4c0d-bbaf-0ee754e4c8ed — 村里長 election root

CecShell CecShell.php

Imports historical election data from the Central Election Commission. Handles pre-2014 elections from CSV files, 2014 final results with CJK encoding fixes, and scrapes 2009–2010 election results from the CEC website.

Election web scraping
MethodPurpose
before2014Imports pre-2014 elections from db.cec.gov.tw repo CSVs. Creates election tree nodes and candidates. Handles 10-field (candidate) and 7-field (party) CSV formats, including president records with pipe-delimited pairs.
final2014Updates 2014 results with final vote counts and winners. Repairs CJK Private Use Area characters → actual Unicode. Falls back to interactive prompting for unmatched candidates.
v20101101TxB2Scrapes 2010 municipal council results from CEC website, caches HTML locally, outputs JSON.
v20091201TxC2Same for 2009 county council elections.
v20100601C1D2Scrapes 2010 township representative results.
treeListHelper: flattens threaded election tree into flat key→id lookup.
utf8Helper: converts Unicode codepoint to UTF-8 bytes.
Dependencies
  • /home/kiang/public_html/db.cec.gov.tw — local clone of CEC CSV repo
  • CEC website for historical scraping methods (may be offline)

ImportShell ImportShell.php

Handles structured imports for 2014, 2016, and 2018 election data. The 2018 import is the most complex — it maps CEC DistrictId codes to the internal election tree across all 9 election types, then imports candidate records with full biographical data.

Election external sources
MethodPurpose
candidate2018Imports 2018 candidates from CEC JSON data. Maps DistrictId to election IDs across all 9 types (市長, 議員, 區長, 區代表, 縣市長, 縣市議員, 鄉鎮市長, 鄉鎮市民代表, 村里長). Creates/updates with name, party, gender, birth, education, experience, platform.
candidate2016Updates 2016 candidate stages from data/2016_candidates.json. Marks presidential and legislative candidates as active (stage=1).
fb_linksImports Facebook links for candidates from tab-delimited file.
reps / reps_fixImports and fixes town representative election structures.
electionsCreates the full 2014 election tree with all 9 types, linked to areas.
areasCreates the 2014 area tree (municipalities → towns → cunli) from data/town.csv and data/villages.csv.
fix2014Cleans up 2014 data issues (duplicate candidates, missing links).
Dependencies
  • /home/kiang/public_html/2018.cec.gov.tw — CEC 2018 data repo
  • data/2016_candidates.json, data/town.csv, data/villages.csv, data/townmast.csv, data/reps.txt

AeShell AeShell.php

Consolidates areas_elections links. When all children of a parent area are linked to the same election, replaces the child links with a single parent link. Cleans up redundant area-election mappings.

Area
MethodPurpose
mainFinds elections linked to multiple areas, groups by parent area, replaces N child links with 1 parent link where all siblings match.
Dependencies
  • Database only — no external files

PolygonShell PolygonShell.php

Downloads Taiwan GeoJSON/TopoJSON boundary files from GitHub and stores polygon geometry in each area's polygons field, matched by government area codes (v_id, town_id, county_id).

Area GitHub download
MethodPurpose
mainDownloads TopoJSON from ronnywang/twgeojson, converts to GeoJSON via vendor libs (GeoTopoJSON, geoPHP), matches features to areas by code within the "2014" root tree, saves geometry as JSON to area polygons field.
Dependencies
  • Vendor: GeoTopoJSON, geoPHP
  • GitHub: ronnywang/twgeojson (downloaded at runtime)
  • Requires area code field to be populated
